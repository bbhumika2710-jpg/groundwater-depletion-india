#Groundwater Depletion and Stress in India
A District-Level Data Visualisation and Statistical Analysis Study

About the project

Analysis of groundwater extraction patterns across Indian districts using CGWB 2025 data.

##Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy
- Google Colab

##Key Findings
- 706 district records analysed.
- Irrigation contributes 87.01% of total extraction.
- Punjab, Rajasthan and Haryana have the highest weighted extraction stages.
Dataset Source

Central Ground Water Board (CGWB), 2025.
